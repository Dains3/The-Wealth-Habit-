# The Wealth Habit

A Pinterest-style personal finance blog built with Next.js 15 (App Router) and React 19.
Covers budgeting, saving, making money online, and side hustles.

## Stack

- Next.js 15 / React 19, TypeScript
- Tailwind CSS 3 (custom deep-green / soft-gold / warm-cream / charcoal palette)
- Google Fonts: Cormorant Garamond (headings) + DM Sans (body), loaded via next/font/google

## Getting started

npm install
npm run dev

Visit http://localhost:3000
